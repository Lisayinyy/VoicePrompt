# Voice Prompt website

Chosen first visual direction: pale ivory, silver-lilac acoustic ribbon and editorial typography. React/Vite implementation, separate from the desktop/MCP runtime.

Run `npm install`, then `npm run dev -- --host 127.0.0.1 --port 4173`.
Build with `npm run build`; static output is `dist/client`. `npm run test:sites` checks the optional bundled hosting adapter.

The preview has functional preset comparisons and native dialogs for downloads, setup and data handling. Download points to the verified v0.7.0-beta.3 Apple Silicon asset. This is not a live recording web app. Public shared polishing and marketplace publication are not claimed.

## Assets

`public/hero-ribbon.png` was generated for this project using the user-selected concept as reference. Icons: @phosphor-icons/react (MIT). Typeface: Inter (SIL OFL, loaded from Google Fonts), native Chinese system fallback. No third-party competitor logos or illustrations are included. Browser requests to the font provider are separate from our site; no analytics, voice collection or signup forms are implemented.

Design verification and screenshots: `design-qa.md`, `qa/desktop.png`, `qa/mobile.png`.
