如何开始使用
  1. 打开 Voice Prompt.app，允许麦克风与辅助功能权限。语音引擎与模型已经包含在应用中。
  2. 把光标放到目标输入框，按 ⌥ 空格开始，说完再按一次。面板里的「暂停 / 继续」可中途停顿。
  3. 等待识别原文填入；@Voice Prompt 并发送后才润色。Esc 可取消录音或处理。
  4. AI 润色需要可用的模型服务；尚未配置时会明确提示并保留原文。
