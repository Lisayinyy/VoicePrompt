# Voice Prompt 内测邀请码激活设计

状态：待评审的产品设计稿。仅设计，不代表已实现、已部署或已更新市场。
日期：2026-09-14

## 目标与范围

受邀同学不需要理解 Provider、模型名、API Key 或接口地址。首次使用时安装必要组件、输入一次邀请码、完成本机系统授权，此后直接按快捷键说话，得到经过 AI 润色的文字并填入原输入框，由本人确认发送。

第一版面向现有 Apple Silicon Mac 桌面产品及 MiniMax Code 插件；同一桌面应用也服务 OMP 等平台。麦克风、系统权限、模型与输入框操作由桌面应用负责；插件负责引导、协助安装、打开激活页及读取状态。激活流程不依赖 MiniMax 具备尚未核实的自定义卡片或表单能力。

## 建议的首次使用流程

### 1. 打开插件：只给一个明确入口

用户在 MiniMax Code 中选中并发送 @Voice Prompt，或进入插件的使用入口时，收到简短欢迎文案：

> 欢迎使用 Voice Prompt
>
> 说出想法，自动整理成清晰的文字
>
> 首次使用请发送「开始使用」
> 我会帮你准备桌面应用，并打开内测激活页
>
> 已经准备好的用户，直接按 Option＋空格即可开始

只选中 @ 标签、尚未发送消息，不等于 Agent 已收到指令，也不应自动录音或安装。若平台未来支持经验证的操作按钮，「开始使用」可变为按钮；第一版保留能实际执行的文字入口。

收到「开始使用」后，Agent 只读检查本机：已安装则直接打开；缺少应用则说明下载规模并协助安装。首次下载沿用当前桌面包约 268 MiB、Qwen 权重约 2.46 GB 的量级，最终以发布清单为准，不承诺几秒完成。插件运行在没有本机工具的云端任务时，明确引导到本地桌面任务，不把云端下载当成本机安装。

### 2. 桌面激活页：只输入邀请码

标题：**开启 AI 润色**

说明：**输入内测邀请码，说完就能自动整理表达**

唯一输入字段：**内测邀请码**

主操作：**激活并继续**

次操作：**先使用本地语音输入**

主操作旁的一行说明：**语音在本机识别；开启润色后，仅将识别文字发送至云端处理**。可展开查看隐私与内测额度说明。模型必须收到转录文字才能润色，不能把该模式标为「全部离线」。

这里不出现 Provider、API Key、Base URL、模型选择，也不要求注册密码或绑定付款方式。邀请码在桌面应用内输入，不要求粘贴到 MiniMax 聊天记录里。

视觉沿用现有 Voice Prompt 的简洁桌面风格：舒适留白、一个字段、一个主按钮，兼顾浅深色可读性。该页是设置窗口；录音浮窗继续沿用现有声波形式，不扩展成大面板。

### 3. 自动准备：让人知道还差什么

邀请码有效后先显示：**内测已激活，正在准备语音输入**。

应用自动配置服务地址、用户独立凭证和润色选项。新用户默认使用 Voice Prompt 内测服务，开启「录音后自动润色」。已有用户自己的有效 AI 配置应保留；明确选择使用内测服务后再切换，不覆盖自定义快捷键、语言或已下载模型。

同一页显示简短的准备状态：

- 本地模型：已就绪，或下载进度及暂停/重试入口
- 系统权限：只显示尚需本人确认的麦克风、辅助功能操作
- AI 润色：连接验证中、可用，或具体可恢复的错误

可以并行下载模型和引导权限，避免无意义的串行等待。激活请求可重试，同一设备的同一次请求不应重复消耗邀请码。下载失败保留缓存；激活成功也不能因模型下载失败而丢失资格。

必须分开保存「内测资格有效」「模型能运行」「麦克风已授权」「自动填入已授权」「AI 请求成功」这些状态；激活接口成功不等于所有功能就绪。AI 验证使用不含个人信息的固定短句，确认真实润色成功，不能只检查配置字段是否存在。

### 4. 第一次试说：在真实输入框里完成

基础准备完成后显示：

> 可以开始说了
>
> 回到 MiniMax Code，点中输入框
> 按 Option＋空格开始，再按一次结束
>
> AI 润色已开启，检查文字后再发送

第一次真实语音与填入仍需要用户试一次。权限显示已允许，并不能替代输入框兼容性验证。应用不主动开启麦克风，不自动发送文字。即使首次测试未成功，也不重新展示邀请码页，而是针对模型、权限、润色或输入框焦点中的具体失败提供处理入口。

### 5. 日常使用：无需再进入激活流程

点击任何已验证支持的输入框 → Option＋空格 → 说话 → 再按一次 → 本地识别 → 云端润色 → 填入 → 用户发送。

用户无需每次 @，无需再次输入邀请码。桌面设置页显示「AI 润色已开启 · 内测中」，可查看有效期/额度、暂停自动润色或退出内测服务。录音过程继续使用简洁声波与必要状态提示。

后续 @Voice Prompt 的用途是首次安装、检查/恢复、查看帮助及整理已有文字，而不是每次录音的开关。

## 邀请码规则：建议默认值，尚未冻结

| 项目 | 第一版建议 |
| --- | --- |
| 分发方式 | 管理员给每个受邀者发独立的一次性邀请码 |
| 输入形式 | 随机生成、可整段粘贴；忽略输入中的空格与大小写，去掉易混淆字符 |
| 兑换有效期 | 发出后 7 天内激活；与激活后的内测资格有效期分开 |
| 设备 | 一码激活一台设备；另一台电脑可补发一个码，暂不做账号注册 |
| 日常鉴权 | 兑换后自动保存独立应用凭证，不拿邀请码充当长期接口密钥 |
| 更新与重启 | 保留激活状态，不重新消耗邀请码 |
| 换机/重装 | 可由管理员撤销旧资格并补发；不靠永久硬件指纹判断身份 |
| 额度 | 后台可调的用户上限及项目总上限；具体次数上线前按预算确认 |
| 付费 | 第一版内测免费，不要求绑卡、不自动收费；后续收费另行设计 |
| 失效 | 停止共享 AI 润色，本地语音输入与历史保留 |

「一次性邀请」证明持有人获得了邀请，不证明其一定从 MiniMax 市场下载。没有平台签发的安装凭证时，对外应写「受邀内测用户可用」，不要承诺严格验证市场安装来源。第一版不建议使用全公司共用的永久通用码。

## 常见状态与用户看到的处理方式

| 状态 | 简短文案 | 下一步 |
| --- | --- | --- |
| 邀请码有误/过期 | 邀请码无效或已过期 | 检查输入或联系邀请人；保留输入 |
| 其他设备已兑换 | 此邀请码已使用 | 当前已激活设备直接恢复；新设备申请新码 |
| 激活时网络失败 | 暂时无法连接，请重试 | 安全重试，不能白白消耗邀请码 |
| 模型未下载完成 | 正在准备本地语音模型 | 看进度、暂停或重试 |
| 未获得系统权限 | 还需要允许自动填入 | 打开对应系统设置，由本人确认 |
| 用户当日额度耗尽 | 今日润色额度已用完，语音输入仍可用 | 返回本地输入，展示重置时间 |
| 项目服务暂不可用 | AI 润色暂不可用 | 保留识别文字，允许继续本地输入 |
| 资格结束或撤销 | 内测资格已结束，语音输入仍可用 | 联系邀请人或自行选择其他 AI 服务 |
| 润色成功、填入失败 | 文字已保留，点中输入框后重试 | 不重新调用模型，不重复计费，不自动发送 |

不能把云端失败说成已经润色；不能把尝试填入说成写入成功。服务失败时默认保留原文，并按已开启的自动填入偏好处理，同时简短注明「本次未润色」。是否写入仍遵守原有焦点保护。

## 背后的职责与密钥边界

- 插件：查看本机准备状态、协助安装、打开桌面激活入口、解释结果；只得到未激活/有效/过期等状态，不读取邀请码或长期凭证。
- 桌面应用：通过正式 HTTPS 地址兑换邀请码，自动保存本设备凭证；Keychain 为首选，具体存储需结合正式签名与升级路径验证。凭证不放入插件目录、安装 ZIP、聊天或日志。
- Voice Prompt 后端：校验邀请、发放独立凭证、管理有效期与撤销、校验额度、调用模型；上游 MiniMax Key 始终只在后端，绝不返回给客户端。
- 管理入口：生成/补发/撤销邀请，查看是否兑换及用量，调整用户和全局限额；不需要收集用户的转录文字来做管理。

需要限制无效兑换尝试，邀请码以安全摘要保存。兑换应原子完成，具备经过同一次兑换身份验证的幂等恢复，防止并发双领和请求超时后无法恢复。客户端请求不传入任意上游地址或模型，避免共享服务被当成通用代理。

## 上线前必须完成的产品验收

1. 一台没有开发者配置的新 Mac，可以从插件引导安装，完成一次邀请码激活。
2. 过程中无需填写 Provider、API Key、模型名、服务器地址，也不需要发布者的 SSH 隧道或 SSH 密钥。
3. 邀请码不会进入 Agent 对话；安装包和配置中没有发布者的 MiniMax Key。
4. 新用户默认开启云端润色；已有用户配置在明确切换前保持原样。
5. 在 MiniMax Code 的真实输入框完成「说话 → 实际 AI 润色 → 实际填入」，保留原意，未自动发送。
6. 重启/更新后无需重新激活；无效邀请码、兑换断网、模型下载失败、额度用尽、云端超时和焦点变化都有可恢复路径。
7. 验证正式 HTTPS、真实上游调用和受邀用户额度；不能用开发者本机的成功代替新设备验收。

## 实施前仍需确认

本稿不实施任何变更。正式 HTTPS 的可用性、共享模型额度的使用范围、内测总预算/个人限额，以及正式签名对凭证保存和升级授权的影响，需要在实现和上线前落实。

建议先评审本稿的「插件引导 → 桌面输入邀请码 → 自动准备 → 日常快捷键」主流程；认可后，再画首次引导、邀请码页和准备完成页三张界面稿。
