## 用户流程

安装 Voice Prompt 桌面应用和模型，确认 macOS 麦克风及辅助功能权限后，按 Option + 空格录音，再按一次结束。本机识别，文字通过 HTTPS 发往 Voice Prompt 后端，由后端调用 MiniMax 润色，返回并填入用户原来的输入框，用户确认后发送。用户不填 API Key 或邀请码。

MiniMax Key 只存于服务端；客户端自动注册独立设备凭证，服务端保存凭证摘要。免费服务继续保留设备与全局用量上限，不对外承诺无限额度。

## 已核实的阻塞

- 域名 voiceprompt.work 已购买；域名注册、实名认证不等于 ICP 备案完成。
- 当前广州域名公网 HTTP 被引导至腾讯拦截页，公网 HTTPS 连接失败；服务器内部带证书校验的 HTTPS 以及真实 MiniMax 润色可用。

- MiniMax 官方说明 Token Plan 面向个人交互式使用，生产环境建议按量付费。订阅存在用量窗口和动态限流；普通生产 API 或获准的共享服务额度更适合正式规模化服务。当前调用成功不证明可无限对外服务。
