# Voice Prompt 官网设计与发布范围

2026-09-11，个人开发者首发，macOS 内测。官网与插件市场上架是两个交付项；用户已选择第一个视觉方向，已实现 website/ 本地预览并完成设计与交互检查；尚未发布到正式域名。

## 核心任务

让访客理解「说出想法 → 整理成清晰的 Prompt → 填回原输入框」，随后下载桌面应用或阅读 MiniMax Code 插件安装指南。发送由用户确认。官网不要求访客上传录音，不在网页里索取模型密钥。

## 参考与差异

- [Handy](https://handy.computer/)：聚焦一个动作，下载入口与实际使用演示靠前，清楚说明本地识别
- [Typeless](https://www.typeless.com/)：用口述到成稿的结果传达价值。仅借鉴演示思路，不复制其版式、商标、速度数字或跨平台承诺
- Voice Prompt 重点是面向 AI 工作的意图整理，保留否定、数字、路径与用户限制；本地语音识别与云端文字润色的数据边界必须说清楚

## 视觉与内容

浅色底、深色字、大面积留白，少用边框和卡片；原创声波作为视觉主线。延续用户认可的轻盈桌面浮层，不用卡通 Handy 品牌元素。中文优先，标题不加句号。

首屏文案建议：

> 想法说出来，Prompt 自然清晰
>
> 按下快捷键，自然表达。Voice Prompt 整理口头禅和重复，把你的意思填回输入框

主动作「下载 macOS 内测版」，次动作「MiniMax Code 使用指南」。上架前不得使用「已上架」或跳到不存在的市场链接；当前版本及系统要求必须来自实际发布包。

演示采用明确标注的示例，不伪装实时模型调用：

- 口述：嗯，帮我看看登录页，按钮好像有点不明显，就是不要改数据库，先给我看看方案
- 整理：请检查登录页，重点改善按钮的辨识度。先提供方案，不要修改数据库
- 末态：填入草稿，等待确认发送

随后是三步安装：安装应用与模型、完成系统授权、在目标输入框使用快捷键。插件帮助配置和连接 Agent，桌面应用负责录音与填入，不宣传只导入 ZIP 就无授权地完成一切。

## 必须准确的说明

- 本地识别不产生云端转录调用费；云端润色会发送转录文字给配置的服务
- 免费内测不等于无限模型额度；共享润色尚未开放前清楚标注
- 仅展示已支持并验证的平台，不宣传移动端或所有软件都保证可用
- 页脚提供源码、版本、使用说明、隐私说明；备案号只在真实取得后填写
- 不收集候补名单或邮箱，直到明确数据用途、存储与删除方式
