## 更新说明（可复制）

新增免费 AI 润色自动开通流程，无需邀请码或用户自行填写模型 API Key。首次 @Voice Prompt 发送「安装」，由 Agent 协助准备桌面应用与语音模型，系统权限由用户确认。打开应用后连接免费润色服务，按 Option＋空格开始录音，再按一次结束；润色后的文字填入输入框，由用户确认发送。支持 Apple Silicon Mac，完整安装流程要求 macOS 15 或更新版本。

语音在本机识别；润色时将文字发送至云端，由 MiniMax 处理。每台设备每天可用 30 次，共享额度繁忙时保留原文。服务密钥只保存在后端。
