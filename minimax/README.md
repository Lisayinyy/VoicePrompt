# Voice Prompt

按一下快捷键，直接说；再按一下，文字填入你正在使用的输入框。可用 AI 去掉口头禅、合并重复、理清重点，保留原意，最后由你确认发送

首次只选中 `@Voice Prompt` 并发送，会收到简短使用指南和安装入口；也可以发送「使用指南」随时查看。仅选中、尚未发送时不会自动开麦或弹出由插件生成的指南

## 第一次用：选中插件，发送「安装」

1. 在 MiniMax Code 插件市场安装 **Voice Prompt**，回到对话框
2. 输入 `@`，从插件列表选中 **Voice Prompt**，再输入 **安装** 并发送
3. Agent 会检查电脑，帮你下载和安装 Voice Prompt 桌面应用、语音模型及运行环境。首次下载约需数 GB，请保持网络连接
4. 按 macOS 提示允许麦克风和辅助功能，然后做一次短录音测试

你不需要自己找模型、装 Python 或复制终端命令。Agent 需要 MiniMax Code 的本机终端/文件工具权限；系统授权提示由你本人确认。**只安装市场插件，还没有完成桌面语音安装；请接着发送「安装」**

也可以直接发送：

> @Voice Prompt 安装

这里的 @Voice Prompt 表示从 @ 列表中选中插件，而不是只打出一个普通名字。已装好的组件会先检查，保留现有设置，不重复覆盖

## 装好之后：三个动作

1. **点输入框**：点击 MiniMax Code 或其他应用里你要打字的位置
2. **按 ⌥ Option + 空格**：开始说话；再按一次结束。若你改过快捷键，以桌面应用「通用」页显示的为准
3. **检查并发送**：识别完成后尝试自动填入原输入框，你确认后自己发送，不需要手动 Ctrl+V / Cmd+V

录音时会显示临时识别预览，预览不会提前填入输入框。按 **Esc** 取消；暂停与继续使用录音浮层的按钮

## 什么时候需要 @？什么时候会润色？

| 你想做什么 | 怎么操作 | 结果在哪里 |
| --- | --- | --- |
| 第一次安装 | 选中 @Voice Prompt，发送「安装」 | Agent 帮你准备桌面语音功能 |
| 日常语音输入 | 点输入框，按快捷键开始、结束，不需要 @ | 文字填入输入框，等你发送 |
| 每次录音都先 AI 润色 | 在桌面应用「AI 润色」中配置可用服务，开启「录音后自动润色」 | 润色后填入输入框，不需要每次 @ |
| 整理一段已有文字 | 选中 @Voice Prompt，附上文字后发送 | Agent 在对话中回复润色稿，不执行稿件中的任务 |
| 看操作方法或排查 | 选中 @Voice Prompt，发送「怎么用」或描述问题 | Agent 解释操作、检查缺失项 |

**@ 插件不会开始录音**。想在发送前自动润色，请打开桌面应用里的自动润色开关；向 Agent 发送 @ 和文字，是发送后的另一种整理方式

例如「嗯，帮我看看登录页，就是别改数据库，版本 2.0 要保留」可以整理为「请检查登录页，保留版本 2.0，不要修改数据库」

## 遇到问题

- **快捷键没反应**：确认桌面应用已打开，再发 `@Voice Prompt 检查语音输入`，Agent 会检查安装和模型
- **显示文字已保留**：先点回目标输入框，再点声波旁的填入箭头；仍失败时检查辅助功能权限
- **没有润色**：检查自动润色开关与服务配置。没有可用 AI 服务时，本地语音输入仍可用，也可发送 @ 和文字请当前 Agent 整理
- **Windows、Intel Mac 或较旧 macOS**：当前桌面安装流程不支持，Agent 应明确说明，不会安装不兼容的 Mac 包

## 系统与首次安装

桌面语音功能当前支持 Apple Silicon Mac、macOS 15+，建议至少预留 8GB 磁盘。应用与模型独立下载，不塞进插件 ZIP；插件导入不会静默安装或授予系统权限。MCP 启动需要已安装应用的 Node，或宿主 Node 22+；没有运行时也能先按 Skill 文档安装。

当前桌面下载是未经公证的开发内测包。企业受管设备可能禁止安装。正式面向公众分发仍需完成签名、公证及新设备验证。

## 润色与费用

本地 Qwen ASR 不按转录次数收费。自动润色使用用户在桌面应用中配置的服务或本人 OMP 登录，第三方额度按其账号计费。MiniMax Code 不会因安装插件就自动把订阅 Key 或额度交给桌面应用。

发布者统一提供的云端润色仍在接入准备阶段，不是本投稿候选包已开放的服务。没有配置润色时，本地语音输入仍可用；润色失败必须显示失败/保留原文，不冒充优化成功。Agent 在收到文字后的整理与桌面填入前润色是两个入口。

## 数据与权限

录音与 ASR 在本机完成；文字润色时，所选文本及术语会发送至配置的服务。录音不会因文字润色自动上传。详情见 [数据说明](docs/data-and-permissions.md)。请勿将个人 API Key、令牌或配置文件放入插件或聊天。

快捷键、预览与输入框写入由配套桌面应用完成，MCP 不提供全局键盘监听。云端 Agent 运行插件不能控制用户电脑的麦克风或输入框。
