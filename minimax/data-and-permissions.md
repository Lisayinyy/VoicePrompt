# 数据、权限与费用说明

适用：Voice Prompt MiniMax 桌面插件投稿候选版 0.7.1

- 本地录音、模型推理及识别预览在使用者电脑运行
- `voice_prepare_prompt` 将明确提供的文字交给本机服务；开启 AI 时，正文与术语交给用户配置的模型服务，处理和留存遵循该服务政策
- `voice_transcribe_file` 只用于用户明确提供的本地 WAV 路径，不搜索其他文件、不启动麦克风
- 本地历史有条数与时效限制；不要把它当长期备份。日志不应记录录音、全文或凭据
- 麦克风用于录音；辅助功能用于向目标应用填入文字。系统授权由使用者本人完成，MCP 安装不授予这些权限
- 通用 macOS 输入兼容路径可能短暂使用并恢复剪贴板。OMP 编辑器接口路径与通用应用路径不同，不能承诺所有软件均完全绕过剪贴板
- 填入后的内容由用户检查并发送；未经验证的目标窗口不应被报告为写入成功
- 本地识别软件内测免费，AI 服务可能收费，使用量跟随配置的服务账号；插件不附送 MiniMax Code 额度
- 发布者统一额度服务尚未对本包开放，不要求提交发布者密钥，也不会从 MiniMax Code 提取或复用其内部凭据

此文件说明当前候选版行为，不替代正式云端服务上线时需要提供的隐私政策、运营主体、联系方式与删除请求流程
