# 数据、权限与免费用量

适用：Voice Prompt 0.8.0

- 录音、Qwen 识别和实时预览在本机运行，录音不会因文字润色上传
- 开启 AI 润色时，识别文字和用户选择的术语通过 HTTPS 交给 Voice Prompt 后端，再由 MiniMax 处理；关闭自动润色可只用本地转写
- 默认服务免费、自动开通，无需邀请码或用户 API Key；每台设备每天 30 次，并受共享总量、并发与防滥用限制。不会自动向用户收费
- 发布者的 MiniMax Key 仅在服务器。客户端独立凭证仅用于 Voice Prompt，保存在本机钥匙串。服务器保存凭证哈希和用量，不保存录音或转录正文；用于限流的网络来源按日哈希，不保存原始 IP
- 服务器不会获取 MiniMax Code 的内部密钥或订阅额度；自定义 AI 服务遵循用户自行选择的服务政策和费用
- 麦克风、辅助功能和必要的钥匙串确认由用户在每台 Mac 分别完成；导入 MCP 不会授予权限
- 自动填入通过系统输入事件完成，不使用剪贴板，也不自动发送。应用切换、光标变化或权限不足时保留草稿
- 本地历史最多 20 条、保留约 1 小时，不应当作长期备份
- 云端模型不可用或内容校验未通过时保留原文，并显示润色未完成。公开服务可随时暂停新的自动开通；已存在的凭证可单独撤销
