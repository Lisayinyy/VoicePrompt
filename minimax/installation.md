# 安装与使用

[返回插件说明](../README.md) · [首次安装流程](agent-setup.md)

## 配置 AI 润色

首次运行桌面应用会准备个人配置。已有配置不要覆盖。API 凭据只能保存在使用者自己的受保护配置中，不应出现在聊天、插件包或版本控制中。

已登录 OMP 的用户可以配置 `provider: "omp"`，将 `ompCommand` 设置为本人可正常调用模型的 OMP 可执行文件绝对路径。使用本人服务额度，不附带发布者账号，不从 MiniMax Code 读取密钥。

兼容 Chat Completions 的服务可配置 `provider: "openai-compatible"`、该服务的 HTTPS `baseUrl`、`model` 与 `apiKeyEnv`。环境变量必须存在于运行桌面服务的进程环境；Finder 启动的应用通常不会继承终端 export。旧版桌面包与最新源码的凭据配置能力可能不同，请核对实际安装版本，不能仅把私有文件路径写进旧配置就认为已生效。

没有可用服务时先使用本地语音输入，或在 MiniMax 中发送 @ 与文字，由当前 Agent 整理。后者不是桌面填入前自动润色。

任何配置完成后，用一句不含秘密的文字验证 `voice_prepare_prompt`，只有 `fallback=false` 才表明润色链路成功；配置存在、HTTP 200 或文字没有变化均不能单独证明这一点。

## 日常使用

点击输入框，按 Option + Space 开始，按同一快捷键结束。打开桌面应用中“录音后自动润色”后，识别结果会先整理，再尝试填入，最后由本人发送。只要桌面应用正在运行，不 @ 也能录音。

取消使用 Esc；暂停/恢复使用声波浮层的对应操作。若显示已保留，请先点回输入框，再点声波旁的填入箭头。仍失败时检查辅助功能权限与实际焦点，不要把重复复制当成完成写入。
